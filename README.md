# 📱 AppEstacionamento

Aplicativo mobile desenvolvido para cadastro e gerenciamento de veículos em condomínios.

## 📌 Sobre o projeto

O aplicativo foi desenvolvido como projeto acadêmico com o objetivo de praticar conceitos de desenvolvimento de aplicações mobile.

A aplicação permite realizar o cadastro e gerenciamento de veículos, centralizando informações relacionadas aos carros dos moradores.

## 🚀 Funcionalidades

- Cadastro de veículos
- Gerenciamento de veículos
- Consulta de veículos cadastrados
- Interface para utilização em dispositivos Android

## 🛠️ Tecnologias

- Java
- Android
- Gradle
- Android Studio

## 🎓 Contexto

Projeto desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas.
